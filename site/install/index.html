Why does my computer warn me?

Because Relay's installers are not code-signed or notarized yet. The warning is expected, and it shows only the first time.

Windows and macOS trust an app more when its maker has paid to prove who they are: a code-signing certificate on Windows, and a paid Apple Developer account for signing and notarization on Mac. Relay is a free project made by one developer, and it doesn't have those yet. (The Mac builds carry only an ad hoc signature, which macOS doesn't treat as an identified developer.)

So the first time you open it, Windows SmartScreen or macOS Gatekeeper says the app comes from an unknown developer. That doesn't mean Relay is harmful. It does mean you should only ever get it from the official GitHub Releases page, because the warning can't tell you whether a copy from somewhere else was changed.

Only download Relay from github.com/CristiMachine25/relay/releases. Not from mirrors, download sites or links in messages.

Every build is made in the open

The installers aren't built on anyone's laptop. GitHub Actions builds them from the public source code, using a release workflow you can read line by line. It runs the tests first, then builds on Windows, macOS and Linux machines and attaches the files to a release.

  1. 01 Public source The code on GitHub, open for anyone to read.
  2. 02 GitHub Actions Runs the tests, then builds each installer.
  3. 03 Releases page The files you download, attached to the release.

If you'd rather not trust a downloaded binary at all, that's reasonable: build Relay from source instead.

Open it the first time

You do this once. After that, Relay opens like any other app.

Windows

  1. Run Relay_<version>_x64-setup.exe (or the .msi). Your browser may first ask whether to keep a file that isn't commonly downloaded; choose to keep it.
  2. SmartScreen shows Windows protected your PC. Click More info.
  3. The publisher shows as unknown. Click Run anyway, then follow the installer.

macOS

  1. Open the .dmg and drag Relay into Applications.
  2. Open Relay. macOS says it can't verify the developer. Close that message; don't move the app to the Trash.
  3. Open System Settings > Privacy & Security, scroll down to Security and click Open Anyway.
  4. Confirm with Open Anyway again (and your password if asked). Relay opens, and from now on it opens normally.

Prefer Terminal? This removes the quarantine flag macOS puts on downloaded apps, which has the same effect:

$ xattr -dr com.apple.quarantine /Applications/Relay.app

Linux

  1. For the .AppImage, make it executable, then run it: 
    $ chmod +x Relay_*.AppImage
$ ./Relay_*.AppImage
  2. For the .deb or .rpm, install it with your package manager as usual. There's no warning to get past.

First run

Relay works with the AI command-line tools you already have. It doesn't install them for you.

  • It finds what's already there. Relay looks for the installed CLIs and their existing config folders, including side-by-side ones like ~/.claude-work. Importing keeps each one where it is and doesn't change its sign-in.
  • Add more accounts from the app. Under Add an account, create a new profile and sign in once: a terminal opens with that tool's own sign-in. Every account keeps its own folder, so switching never means logging out.
  • Live usage is your call. With Check usage live on, Relay sends each account's own login token only to that provider's servers to read its limits. Turn it off in Settings to use local session logs only.

Update and uninstall

Updating

Relay doesn't update itself yet. When a new version comes out, download it from Releases and install it over the old one (on Linux, replace the AppImage). Your accounts, settings and history carry over. To hear about new versions, watch the repository's releases on GitHub.

Relay used to be called Agent Hub, so its data folders still use the internal id dev.switchyard.app. That's on purpose: it keeps upgrades seamless.

Uninstalling

Uninstall Relay the normal way for your system: Settings > Apps on Windows, drag it from Applications to the Trash on macOS, or remove the package or AppImage on Linux. Your AI tools' own folders, such as ~/.claude, are left alone.

Relay's data folder stays behind unless you delete it, so a reinstall picks up where you left off. It holds your accounts list, settings and history, and by default a profiles folder with the account folders Relay created for you, including their sign-ins. Delete it only if you want a completely clean slate:

Where Relay keeps its data
SystemData folder
Windows%APPDATA%\dev.switchyard.app
macOS~/Library/Application Support/dev.switchyard.app
Linux~/.local/share/dev.switchyard.app

Build from source

You'll need Node.js 22.12 or newer, Rust (stable) and the Tauri prerequisites for your system. Then, in a clone of the repository:

$ npm install
$ npm run app:dev     # run the desktop app with hot reload
$ npm run app:build   # build installers into src-tauri/target/release/bundle

Builds you make yourself are unsigned too, but they come from code you can read. More detail is in the README.
